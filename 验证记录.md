# v1.2.0 验证记录

## 功能模拟回归

- 1.0 storage migration preserves collection; card retains collect/cancel and live collected count; no collection panel
- Two independent persistent switches: all four combinations; image actions disappear on OFF
- Main/A+ DOM filtering and duplicate-image removal
- Full pipeline: background image bytes, 404 fallback, max-three pool, worker failure fallback and detail ZIP naming
- Image bridge rejects non-CDN URLs, non-image paths and requests while disabled
- Post-reload session marker is consumed once and produces A+-only ZIP
- Concurrent collection and image-toggle writes preserve existing and newly collected ASINs
- Dynamic cards retain live collected count; clicking count opens no panel
- Popup second switch persists while displaying the existing ASIN list
- Mobile session rule: current tab/domain only, mobile headers, URL, cleanup
- Clear-all persists empty list, syncs counts, preserves both switches

另通过：旧 I/G 目录 A+、移动主图容器、延迟 DOM 恢复、一次超时后的同 URL 重试。

## 实际样本

B0CMHT536M 桌面 HTML：7 张高清主图、8 张 A+。15 个实际图片请求全部成功并通过图片解码；主图长边 1500px。真实图片字节进入插件 ZIP 生成流程，15 张图片加 3 个 JSON，CRC 与逐文件字节核对通过。

手机请求取得 HTTP 200 页面，初始 HTML 提取 7 张主图、3 张 A+。

## 未验证范围

浏览器直接导航返回 ERR_BLOCKED_BY_CLIENT。没有完成真实 Chrome 中安装插件后的逐按钮、移动 DNR 规则生效及自动下载全链路测试。模拟 API、实际 HTTP 和文件测试分别成立，不能合并宣称端到端测试通过。
